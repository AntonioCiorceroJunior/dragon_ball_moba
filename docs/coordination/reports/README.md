# Histórico de entregas do Codex

Um arquivo Markdown por execução, no formato `YYYY-MM-DD_DBM-NNN_tema.md`, com base em [`../REPORT_TEMPLATE.md`](../REPORT_TEMPLATE.md).

O relatório deve registrar código realmente alterado, commit SHA, testes executados, falhas, limitações, evidências, assets e decisões pendentes. Relatórios anteriores não devem ser sobrescritos.

O resumo da entrega mais recente fica em [`../FROM_CODEX.md`](../FROM_CODEX.md).
