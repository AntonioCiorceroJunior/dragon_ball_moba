# Código-fonte

## `client-unity/` — vertical slice offline v0.1

O código-base inicial do gameplay está pronto para **importação e validação local** no Unity 6. Veja `client-unity/README.md` para iniciar. Foram implementados movimento, ataque, Ki, treino XP, níveis, formas, habilidades Q/W/E/R, 3 rotas, ondas, torres, núcleo, bots e loja simplificada. Tudo com placeholders próprios e sem assets de terceiros.

Não é multiplayer e ainda **não foi compilado** aqui. Próxima tarefa do Codex: `tasks/ACTIVE_TASK.md`.

Módulos futuros do servidor dedicado, autenticação, matchmaking e infraestrutura permanecem planejados, mas não implementados.
